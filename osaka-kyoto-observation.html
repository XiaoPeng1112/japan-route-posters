购买 餐饮 电车交通 观察重点

必买 / 可买

  • ICOCA：关西机场入境后先买，地铁、京阪、JR、便利店都能用。

  • 伴手礼：梅田百货 B1、京都站伊势丹、关西机场。

推荐吃法

  • 黑门市场：海鲜丼、玉子烧、烤扇贝，轻体验即可。

  • 梅田：百货高层食堂，日本中产消费模型。
  • 京都：咖啡店早餐、定食、乌冬、洋食店，少排网红店。

D1

抵达大阪：第一次进入日本都市

夜经济｜亚文化｜高密度商业｜第一次进入日本

09:30 抵达关西国际机场完成入境、行李、海关。第一件事先买 ICOCA。
ICOCA机场秩序
10:30 前往大阪市区南海电铁空港急行：关西机场 → 难波，约 45 分钟。
南海电铁
12:00 黑门市场轻体验不要把这里当纯海鲜市场，重点看游客比例、中文化程度、商贩服务模式。
海鲜丼 / 玉子烧 / 烤扇贝饮料和轻零食
下午 日本桥电器街Animate、二手店、扭蛋机、女仆店，观察 ACG 工业、循环消费、微型娱乐经济。
扭蛋 / ACG 小物关西化亚文化
16:00 道顿堀 & 心斋桥日本桥 → 道顿堀 → 戎桥 → 心斋桥 → 法善寺横丁。看广告文化、街头秩序、游客与本地人的空间分层。
松屋 / やよい軒 / 王将 / Sukiya夜经济
21:30 回肥后桥，可加中之岛如果体力还行，去中之岛散步，会看到和难波完全不同的白领大阪。
市内地铁另一个大阪
DAY 1 的关键不是“到此一游”，而是从难波、日本桥、道顿堀直接进入大阪的商业密度。
D2

大阪现代都市观察日

商业系统｜地下空间｜中产生活｜现代大阪

09:00 前往梅田梅田是大阪真正的 CBD 核心，更像日本中产社会样本。
肥后桥 → 梅田CBD
上午 阪急百货 → LUCUA → Grand Front → 地下街观察百货分层：B1 食品、中层上班族、高层餐饮。地下街像地下城市，重点看导视、无障碍、人流效率。
百货食品 / 伴手礼地下空间
13:00 百货高层食堂这是日本中产消费模型，比排网红店更适合这天主题。
百货高层餐厅
下午 中崎町老木屋、独立咖啡店、小众服装店、年轻创业者。这里代表日本老城区再生。
咖啡休息小众杂货
18:30-19:30 HEP FIVE 摩天轮看日落、蓝调时刻、夜景亮灯。真正意义是从高空理解大阪：JR 铁路网、高密度住宅、商业区、河流系统。
高空理解大阪
晚上 中之岛夜景这是大阪白领世界，和难波完全不同。
办公区夜景
梅田不是景点堆叠，而是商业系统、通勤系统和地下城市的集合。
D3

从大阪进入京都

城市切换｜节奏变化｜京都夜晚

上午 肥后桥 & 淀屋桥慢走看上班族、便利店早餐、通勤节奏、河边办公区。这是大阪最真实的办公区。
便利店早餐路上补给
10:00 退房，11:00 前往京都推荐京阪电车：淀屋桥 → 清水五条，这是最有“进入京都感觉”的路线。
京阪电车
13:00 京都入住 / 放行李下午不要太赶，京都是需要慢下来的城市。
下午 清水五条 → 鸭川 → 祇园 → 花见小路用步行完成城市切换：从大阪速度进入京都节奏。
河流公共空间定食 / 乌冬 / 荞麦面
20:00 后 二年坂 / 三年坂安静石板路、昏黄灯光、几乎没人。白天根本不是一个世界。
最值得体验之一
DAY 3 晚上是整趟旅行的转场：从大阪的灯光进入京都的静。
D4

京都完整深度观察日

清晨京都｜慢生活｜传统与现代｜地方城市感

05:30-06:00 起床，二年坂 / 三年坂清晨清晨能听到鸟叫、扫地声、木门声和很轻的人声。上午 9 点后旅行团和修学旅行会迅速出现。
安静的京都
07:00 清水寺游客少很多，更容易观察本地参拜者、学生、老年人、清晨寺院秩序。
寺院秩序
08:30 京都咖啡店早餐京都是日本最强咖啡城市之一：大学生多、文艺氛围强、慢生活、阅读文化。
咖啡店早餐小包装茶点
10:00 鸭川慢走，11:30 祇园 / 花见小路鸭川代表日本人如何使用公共空间；祇园看小料亭、和服店、小巷尺度和行人秩序。
公共空间
下午方案 A：京都深度慢走祇园 → 八坂神社 → 知恩院外部 → 青莲院周边 → 鸭川。核心不是看多少，而是感受京都为什么和大阪不同。
下午方案 B：宇治半日京阪电车去宇治，看住宅区、河流城市、学生生活、地方铁路、茶文化。
京阪电车抹茶 / 茶点宇治茶
晚上 再次去东山夜晚清水五条 → 宁宁之道 → 二年坂 → 三年坂。京都夜晚每天气氛都不一样。
DAY 4 是整趟旅行核心：不赶景点，观察京都的声音、尺度和日常生活。

京都最后半日 → 关西机场 → 上海

收尾｜京都日常｜离开日本前最后观察

07:30 京都最后一次清晨散步鸭川，或者清水五条周边小街道。看上班族、学生、早餐店、通勤自行车、安静住宅区。
日本日常
09:00 早餐，10:00 退房酒店寄存行李，轻装继续活动。
喫茶店 / 定食早餐水和路上零食

拉面小路 / 乌冬 / 洋食伊势丹伴手礼
上午方案 B：鸭川发呆 + 咖啡店找一家河边咖啡店或京都喫茶店坐 1 小时。
咖啡

HARUKA 特急
